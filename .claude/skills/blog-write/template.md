`<...>` を埋める。使わない見出しは消す。

```toml
+++
title = "<タイトル>"
date = "<YYYY-MM-DDTHH:MM:00+09:00>"
draft = true
```

## Zenn front matter（`--zenn` のとき）

```yaml
---
title: "<タイトル>"

type: "tech"
topics: ["<android>", "<kotlin>"]

---
```

## タイトルの付け方（本人の実例）

- 「〜するには？」「〜するには」: `MCPサーバーをリモートで動かすには？`, `Android ProjectでKotlin2.0にアップデートするには`
- 「〜を読む(言語)」「〜を読んで」: `MCP Quickstart For Server Developersを読む(TypeScript)`
- 「〜のメモ」「〜したときのメモ」: `Android targetSdkVersionを28から30への変更したときのメモ`
- 「〜してみた」「〜を始めてみた」: `Fleet IDEを使ってKotlin Multiplatformを始めてみた`
- 「〜の作り方」: `Custom Gradle Pluginの作り方`
- 「〜で気をつける３つのこと」（全角数字も可）
- 「〜あるある」「〜の現状」（スライド）
- 振り返り: `2024年振り返り`, `2024年の目標`
