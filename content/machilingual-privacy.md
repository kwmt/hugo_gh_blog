英語学習アプリ「マチリンガル」（machilingual、以下「本アプリ」）における個人情報および
利用データの取り扱いについて説明します。

最終更新日: 2026年8月29日

## まとめ

- **アカウント登録・ログインは不要**です。氏名・メールアドレス・電話番号を求めることはありません。
- **録音した音声は端末の外に出ません。** 発音の採点は端末内で完結します。
- サーバーへ送るのは、**教材の英文**と、**ランキングに参加した場合の匿名の識別子・ニックネーム・
  週間スコア**だけです。
- **広告は表示せず、広告目的のトラッキングも行いません。**

## 1. 収集しない情報

本アプリは以下を収集しません。

- 氏名、メールアドレス、電話番号、住所などの連絡先情報
- 端末の連絡先、カレンダー、写真ライブラリ、位置情報
- 広告識別子（IDFA / 広告 ID）

## 2. マイクと録音した音声の扱い

本アプリは発音を採点するためにマイクを使用します。

**録音した音声はお客様の端末内でのみ処理し、当方のサーバーを含む外部へ送信しません。**
採点は端末上で動作する音声認識モデルによって行われます。

「1分ガイド」で録音した音声は端末内に保存され、アプリの設定画面からお客様自身で削除できます。
削除するとファイルごと消え、復元はできません。

## 3. サーバーへ送信する情報

本アプリがネットワーク越しに送信する情報は、以下がすべてです。

### 3-1. 教材の英文（発音記号の生成）

練習する英文（アプリに収録された教材の文）を送信し、発音記号を受け取ります。
**お客様が入力・発話した内容ではありません。** 送信するのは教材に収録済みの英文のみです。

### 3-2. ランキングに参加した場合の情報

ランキング機能は**任意**です。参加を選んだ場合にのみ、以下を送信します。

| 送信する情報 | 内容 |
| --- | --- |
| 匿名の識別子 | 端末ごとにサーバーが発行する文字列。氏名等とは結び付きません |
| 認証トークン | 上記識別子と対になる文字列 |
| ニックネーム | サーバーが自動生成した表示名。お客様が変更した場合はその名前 |
| 週間スコア | その週に獲得した経験値（数値のみ） |

参加しない限り、これらは**1バイトも送信されません**。参加をやめる操作（退会）を行うと、
サーバー上の該当データは削除されます。

### 3-3. 学習内容の配信の受信

レッスンや街の情報を最新化するため、サーバーから配信内容を受信します。
これは**受信のみ**で、お客様の情報は送信しません。

## 4. 端末内にのみ保存する情報

以下は端末内のデータベースに保存され、外部へ送信することはありません。

- 練習した文とその点数、連続記録、獲得した経験値、実績
- 発音の採点結果（発音・リズム・つながりの各指標）
- 「1分ガイド」の録音ファイル

アプリを削除すると、これらは端末から消去されます。

## 5. 外部からのダウンロード

本アプリは以下を GitHub のリリースページから取得します。取得の際、GitHub に対して
IP アドレスなど通常のウェブアクセスに伴う情報が送信されます（GitHub のプライバシー
ポリシーが適用されます）。

- 発音採点用のモデル（約340MB）— **取得は任意**です。お客様が設定画面で明示的に
  開始したときのみダウンロードします。取得しなくても録音・お手本の再生・練習の進行は
  すべて動作し、点数が出ないだけです。
- 街の写真パック — 街ごとに、お客様が取得を選んだときのみダウンロードします。

## 6. 第三者への提供

お客様のデータを第三者へ販売・提供することはありません。

本アプリのサーバーは [Render](https://render.com/) 上で稼働しており、同社のインフラ上に
データが保存されます。

## 7. 子どものプライバシー

本アプリは特定の年齢層を対象としたものではありませんが、上記のとおり個人を特定する情報を
収集しません。

## 8. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改めます。
